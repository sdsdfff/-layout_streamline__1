## Состав

- `dist/` — весь работающий сайт: HTML, CSS, JavaScript, JSON, шрифты и изображения.
- `dist/index.html` — главная страница.
- `dist/projects/` — сборник проектов и отдельные страницы.
- `dist/assets/` — изображения, включая исходные и улучшенные варианты.
- `dist/thanks.html` — страница после заявки на обратный звонок.
- `REDESIGN-NOTES.md`, `PHOTO-AUDIT.json` — заметки по изменениям и изображениям.

Сайт статический, без сборки, npm и серверной базы данных. Папка dist содержит исходники, а не только скомпилированную сборку. История Git, данные доступа и настройки привязки к хостингу ChatGPT в архив не включены.

## Перенос в GitHub

1. Распакуйте архив.
2. Создайте пустой репозиторий GitHub.
3. Загрузите содержимое папки `streamline` в репозиторий, сохранив структуру папок. Не загружайте только ZIP: распакованные файлы удобнее редактировать и публиковать.
4. При использовании Git выполните в папке `streamline`:

```sh
git init
git add .
git commit -m "Import Streamline website"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

Замените YOUR_GITHUB_REPOSITORY_URL на адрес своего репозитория. Сам по себе перенос кода в GitHub не публикует сайт.

## Локальный просмотр

Установите Python 3, откройте терминал в папке streamline и выполните:

```sh
python -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. Не запускайте index.html двойным щелчком: браузер может блокировать загрузку JSON через fetch.

## Публикация на другом хостинге

Укажите `dist` как корневую публичную папку. Команда сборки не нужна. Все пути `/assets/`, `/projects/`, `/redesign.css` и другие абсолютные пути рассчитаны на публикацию в корне домена.

Для GitHub Pages с адресом вида username.github.io/repository/ потребуется адаптация абсолютных путей под /repository/. Без такой адаптации используйте сайт в корне username.github.io или собственный домен. Включение GitHub Pages и настройка его публикации в этот экспорт не входят.
